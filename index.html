How it works

Exits are possible spawns — each match only uses some of them. Use Play mode to track what you've found.

Play mode

  • Tap an exit to cycle: Spawned → Not here → unknown.
  • Turn on Hide ruled-out to declutter as you scout. Reset match clears it for the next round.
  • Filter by Cellar, Gate or Car with the chips.

Edit mode

  • Pick a type, then click the map to place an exit. Drag to move. Select one to add a note or delete it.
  • Drop a map screenshot onto the map (or use Upload image) — it's saved in this browser.
  • Edits save in this browser. Export exits.json and put it next to index.html on your host so everyone sees them.
